# Day 5 Revision Notes -- Operators in Python

## Operator

An operator is a symbol that performs an operation on one or more
operands.

## Arithmetic Operators

`+  -  *  /  //  %  **`

-   `/` → Division
-   `//` → Floor Division
-   `%` → Remainder
-   `**` → Power

## Assignment Operators

`=  +=  -=  *=  /=  //=  %=  **=`

## Comparison Operators

`==  !=  >  <  >=  <=`

Return `True` or `False`.

## Logical Operators

-   `and`
-   `or`
-   `not`

## Identity Operators

-   `is`
-   `is not`

Remember: - `==` compares values. - `is` compares object identity.

## Membership Operators

-   `in`
-   `not in`

## Bitwise Operators

`&  |  ^  ~  <<  >>`

## Operator Precedence

``` python
2 + 3 * 4      # 14
(2 + 3) * 4    # 20
```

## Common Mistakes

❌ `if age = 18:`

✅ `if age == 18:`
