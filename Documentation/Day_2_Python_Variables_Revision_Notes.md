# Day 2 -- Python Variables (Short Revision Notes)

## Variable

A variable is a **name (reference)** that points to an object in memory.

``` python
name = "Sanjana"
age = 22
```

## Why Variables?

-   Store data
-   Reuse values
-   Improve readability

## Variable vs Object

-   Variable = Label/Reference
-   Object = Actual value in memory

## Dynamic Typing

``` python
x = 10
x = "Hello"
x = 3.14
```

## Naming Rules

**Valid**

``` python
student_name = "Raj"
_marks = 95
age2 = 20
```

**Invalid**

``` python
2age = 20
student-name = "Raj"
class = "Python"
```

Use **snake_case**.

## Keywords

if, else, for, while, class, return, True, False, None

## type()

Returns the data type.

## id()

Returns the unique identity of an object.

name="Sanjana"
print(id(name))

## Multiple Assignment

``` python
a = b = c = 10
name, age = "Sanjana", 22
```

## input()

Returns a string by default.
