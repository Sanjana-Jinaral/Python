# Day 1 Revision Notes -- Python Fundamentals

## 1. Programming

**Definition:** Programming is the process of writing instructions in a
programming language to tell a computer what to do.

**Keywords:** Instructions, Logic, Problem Solving.

------------------------------------------------------------------------

## 2. Program

A **program** is a collection of instructions that performs a specific
task.

**Example:** - Calculator program - Login program

------------------------------------------------------------------------

## 3. Software

Software is a complete application made up of multiple programs working
together.

**Examples:** - WhatsApp - Google Chrome - Microsoft Word

### Program vs Software

  Program                          Software
  -------------------------------- ------------------------
  Performs a specific task         Complete application
  Single or related instructions   Collection of programs
  Smaller                          Larger

------------------------------------------------------------------------

## 4. Programming Language

A programming language is used to communicate instructions to a
computer.

**Examples:** Python, Java, C, C++, JavaScript.

------------------------------------------------------------------------

## 5. Types of Programming Languages

### Low-Level Languages

-   Machine Language
-   Assembly Language

**Pros:** Fast, hardware control

**Cons:** Difficult to learn and debug

### High-Level Languages

-   Python
-   Java
-   C#
-   JavaScript

**Pros:** Easy to read, write, and maintain

------------------------------------------------------------------------

## 6. Python

**Definition:** Python is a high-level, interpreted, general-purpose
programming language known for its readability and simplicity.

### Creator

-   Guido van Rossum

### First Release

-   1991

### Name Origin

-   Inspired by *Monty Python's Flying Circus*

------------------------------------------------------------------------

------------------------------------------------------------------------

## 9. Compiler vs Interpreter

  Compiler                       Interpreter
  ------------------------------ --------------------------------------------------
  Translates the whole program   Executes code step by step
  Faster after compilation       Easier debugging
  Example: C, C++                Example: Python (via bytecode + PVM), JavaScript

------------------------------------------------------------------------

## 10. Python Execution Flow

``` text
Python Source Code (.py)
        ↓
Compiler
        ↓
Bytecode (.pyc)
        ↓
Python Virtual Machine (PVM)
        ↓
Machine Code
        ↓
Output
```

### Bytecode

Intermediate code generated from Python source code.

### PVM (Python Virtual Machine)

Executes bytecode and produces the program output.
